# 口服液瓶盖瑕疵检测系统 — 操作说明

## 一、首次部署（在新电脑上安装）

> 如果系统已经在运行中，请直接跳到第 **二** 章。

### 1.1 方案一：离线包部署（推荐）

从管理员处获取离线部署包 `AutoTune_Package.zip`，按以下步骤操作：

1. 将压缩包复制到电脑的 **D 盘根目录**（或其他空间充足的磁盘），右键解压
2. 进入解压后的 `AutoTune_Package` 文件夹，**双击运行** `setup_from_package.bat`
   - 系统会自动解压 Python 运行环境（耗时 3~10 分钟，请耐心等待）
   - 解压完成后会提示你配置 API Key
3. 用记事本打开 `auto_tune\config.yaml`，填入 API Key（向管理员索取）：
   - 找到 `api_key: YOUR_DEEPSEEK_API_KEY`，替换为实际的 Key
   - 找到 `api_key: YOUR_QWEN_API_KEY`，替换为实际的 Key
   - 保存文件并关闭
4. 环境部署完成！

### 1.2 方案二：联网安装（备选）

如果电脑可以连接互联网，也可以直接运行安装脚本自动部署：

1. 确保已安装 Miniconda（下载地址：https://docs.conda.io/en/latest/miniconda.html）
2. 双击运行 `setup.bat`
   - 脚本会自动创建 conda 环境并安装所有依赖（耗时 5~15 分钟）
   - 安装完成后会提示配置 API Key
3. 同方案一第 3 步，填写 API Key

## 二、如何启动系统

### 2.1 启动服务器

**方式一（推荐）**：双击 `start_app.bat`，系统会自动检测运行环境并启动。

**方式二**：打开终端（cmd），执行以下命令：

```bash
conda activate auto_tune
python -m auto_tune.main
```

启动成功后，终端显示如下内容，表示系统已就绪：

```
============================================================
  Auto-Tune Dashboard
============================================================
  Module A: Dataset Analyzer    [OK]
  Module B: Training Analyzer   [OK]
  Module C: Auto-Tuning Agent   [OK]
============================================================
Auto-Tune Dashboard at http://127.0.0.1:8000
```

### 2.2 打开界面

打开电脑上的浏览器（推荐 Chrome 或 Edge），在地址栏输入：

```
http://127.0.0.1:8000
```

按下回车键，即可看到系统主界面。

### 2.3 关闭系统

直接在终端按 `Ctrl + C` 即可关闭服务器。

系统有 5 个标签页：

| 标签页 | 用途 |
|--------|------|

| **历史记录** | 查看过去的训练记录 |

## 三、详细操作步骤

### 3.1 填写数据集路径（第一步）

**用途**：把拍摄的瓶盖图片所在文件夹路径告诉系统，让系统了解要检测什么样的瑕疵。系统支持直接填写服务器上的文件夹路径，无需上传 ZIP 文件。

**操作步骤**：
1. 点击 **数据集报告** 标签页
2. 在"数据集路径"输入框中，填写服务器上图片文件夹的完整路径
   - 例如：`D:\datasets\example_project`
   - 文件夹内应包含图片（jpg/png）和对应的标注文件（txt）
3. 也可以点击 **浏览...** 按钮，在弹出的对话框中浏览选择文件夹
4. 点击 **分析** 按钮
5. 等待系统分析完成（约 10-30 秒，取决于图片数量）

**完成后看到什么**：
- 系统会显示数据集的质量评分（0-100 分）
- 显示图片总数、标注数量
- 显示图片质量分析：模糊率、过曝率、欠曝率
- 如果有问题，系统会提示"关键问题"

### 3.2 划分数据集（第二步）

**用途**：把数据集分为训练组和验证组，一部分用来训练模型，一部分用来检验效果。

**操作步骤**：
1. 上传数据集成功后，在 **数据集报告** 页面点击 **数据集划分** 按钮
2. 系统自动按 80/20 比例划分（80% 训练，20% 验证）
3. 划分完成后会显示训练图片数和验证图片数

> **注意**：如果之前已经划分过，不需要重复操作。

### 3.3 配置训练参数（第三步）

**用途**：设置训练用的检测模型、训练轮数等参数。

**操作步骤**：
1. 点击 **训练监控** 标签页
2. 在训练参数区域，设置以下参数：
   - **模型选择**：默认 `yolov8n.pt`（轻量模型，速度快），可选更大的模型
   - **训练轮数**：默认 100 轮
   - **批次大小**：默认 16
   - **图片尺寸**：默认 640
3. 确认数据集路径（data.yaml）已正确填写

### 3.4 开始训练（第四步）

**用途**：让系统正式开始训练模型，学会检测瓶盖瑕疵。

**操作步骤**：
1. 设置好参数后，点击 **开始训练** 按钮
2. 在"训练日志"区域会实时显示训练进度
3. 可以看到每一轮的 mAP50 指标变化

**训练过程中可以**：
- 实时查看训练日志
- 如发现异常，可以随时点击 **取消训练** 按钮停止

**训练完成后**：系统会显示"训练完成"。

### 3.5 查看分析结果（第五步）

**用途**：了解训练好的模型表现如何，有哪些问题需要改进。

**操作步骤**：
1. 点击 **智能分析** 标签页
2. 查看系统给出的分析结果：
   - **指标展示**：mAP50、mAP50-95、精确率、召回率
   - **关键问题**：是否过拟合、欠拟合等
   - **大模型分析报告**：用文字描述模型表现
   - **混淆矩阵分析**：各类别检测效果
   - **错误裁剪分析**：分析模型犯错的图片

### 3.6 自动调优（进阶功能）

**用途**：让系统自动调整训练参数，尝试找到更好的模型。

**操作步骤**：
1. 在 **智能分析** 标签页，点击 **自动调优** 按钮
2. 选择评估模式：**全面模式**（四项指标综合评分）或 **快速模式**（只看 mAP）
3. 设置最大重试次数（建议 3 次）
4. 点击启动，系统会自动进行多轮调优
5. 每轮训练完成后，系统会自动分析效果并尝试改进参数
6. 全部完成后，系统会展示**最佳迭代**的结果

> **自动调优结束后**：点击"查看完整分析"可以查看详细报告，点击"保存报告"可以把报告保存为 TXT 文件。

## 四、常见问题

### Q1: 系统启动后浏览器打不开？
确保服务器终端窗口在运行，且地址输入正确：`http://127.0.0.1:8000`

### Q2: 数据集分析失败？
- 确保填写的文件夹路径在服务器上真实存在
- 文件夹内应包含图片（jpg/png）和对应的标注文件（txt）
- 图片不要太大，建议不超过 2000 张
- 也可以尝试使用 ZIP 压缩包上传方式（联系管理员）

### Q3: 训练卡住了怎么办？
- 等待几秒钟，系统可能正在加载
- 如果长时间无响应，点击 **取消训练** 重新操作

### Q4: 怎么看训练结果好不好？
主要看这几个指标：
- **mAP50**：越高越好，超过 0.7 表示效果不错
- **精确率（Precision）**：检测出的瑕疵中正确比例
- **召回率（Recall）**：实际瑕疵中被检测出的比例
- **综合评分**：系统综合以上指标给出的分数

## 五、注意事项

1. **每次训练前**，确保数据集已上传并划分完成
2. **训练过程中**，不要关闭浏览器或终端窗口
3. **自动调优耗时较长**，一次 3 轮调优可能需要数小时
4. **如有疑问**，联系项目负责人
