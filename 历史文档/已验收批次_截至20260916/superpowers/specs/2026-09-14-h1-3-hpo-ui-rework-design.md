本节为艾卡在独立初审后的最新批准，优先于下文要求把全部配置/详情铺在主界面的呈现方式。功能保留，隐藏技术复杂度，不降低契约或安全校验。

主界面仅显示当前数据集与模型摘要、试验次数/每次轮数、单一开始入口、进度、最佳指标、使用最佳参数正式训练、最终模型入口。算法默认TPE；种子/超时/完整快照ID/搜索范围/六参数明细/完整Trial表/审计/同条件验证默认折叠，不自动调用LLM。当前数据集默认使用其已登记且有效的绑定快照；不得按全局最新时间选择其他原目录快照。无可靠绑定时仅引导用户确认当前目录的快照，未建立合法绑定不能开始；不静默复制数据或创建快照。模型默认使用当前项目/训练配置合法本地权重，不能从下载列表自动挑best.pt。默认配置不合法、来源不明或权重缺失时提示一次必要选择，不擅自换数据/模型。

搜索默认trial10、每次30轮，其余合法条件继承当前训练配置；缺失时按既有配置默认batch16、imgsz640、device cpu、seed42、timeout3600回退。必须向用户展示实际数据/模型与简短算力预算摘要，点击开始才能训练。草稿保存值和历史冻结值分别标识；原研究值不得覆盖新建或正式配置。

正式训练六参数自动从当前rank1重建；epochs/batch/imgsz/device默认取当前普通训练配置的合法值，epochs来自training.default_epochs，缺失时100，batch16/imgsz640/device cpu。四项可在折叠“调整训练条件”编辑，启动前摘要显示实际值。不得默默采用验收研究的epochs1/imgsz64作为正式默认。候选不适配正式epochs时拒绝并提供安全修正提示，不裁剪六参数。正式训练永不自动启动。

模式选择与主操作固定在共同控制区顶部，HPO新建表单/结果卡片不能插到其上方推动选择栏。必要共享布局调整让四模式统一，不改变其他三模式业务。主页面只保留一个开始操作，创建成功启动失败才显示READY显式重试启动；后台create与start接口仍分离。运行状态决定停止/恢复是否显示；失败和下一步始终可见，不能默认折叠错误。

## 1 范围与替代关系

本文件补充 2026-09-09 H1.3 规格，替代其中 HPO 页面呈现和“只有固定配置验证”的产品限制；其余搜索、排名、并发门禁、停止、恢复、绑定验证和安全契约继续有效。旧实现提示词不再作为本轮编码入口。既有固定配置验证接口保持兼容。

不做全站重设计、LLM 策略修改、基线实验、剪枝、新搜索参数、Classify、Docker、Research、Cloud。四模式共享页面仅允许必要的布局协调，不改变其他三模式业务语义。

## 2 四模式统一呈现

干运行、按原参数训练、HPO、大模型调参保持原顺序。模式选择、主要操作、配置、进度、结果区域保持共同的布局与样式；切换不将选项栏移到另一位置，不让 HPO 在公共按钮下额外堆出独立页面。沿用现有字体、卡片、间距、表格、按钮体系，不引入 UI 框架。

HPO 两块内容为“搜索配置与评价方式”“最佳结果与参数使用”，替换同位置的 LLM 内容。不得显示 LLM 理由、生成解释或虚构修改建议。搜索内容来自 search_space.py 的运行时常量/规则，展示六参数及条件化范围，目标为验证集最佳 epoch 的 mAP50-95；固定条件与搜索参数明确区分。

新建草稿与当前任务详情分开。详情显示权威冻结值：创建时间、算法、预算、每次轮数、Batch、imgsz、设备、种子、快照、模型；编辑草稿不能修改历史研究。术语使用“试验次数（包含失败/取消槽）”“每次训练轮数”“图像尺寸”“计算设备”“最佳指标所在轮次”。COMPLETED 表示预算已执行完，不保证精度提高；同分结果标为同分，不宣传提升。

## 3 选择输入与开始

快照优先使用已发布快照选择器，展示数据集名称、短 ID、创建时间及图片数量；完整 ID 可在详情查看，不要求手抄。即使 latest_dataset 未绑定快照，也能选择受控根中的旧合法快照。无快照时提示去数据集页创建，不静默替换数据。

权重提供项目已有本地文件选择能力；如果现有选择器仅支持目录，增加最小本地 .pt 文件选择接口，不新增依赖、不自动下载、不扫描系统磁盘。保留可输入绝对路径作为回退。确认区展示实际绑定权重。选择不等于可信，创建仍由现有服务验证文件与哈希。

HPO 主要新建按钮为“创建并开始调优”，始终按当前草稿创建新研究，不因已选历史研究而启动旧研究。后台 create/prepare 和 start 继续分离，前端串行调用；创建成功而启动失败时保留 READY ID 并提供明确的“启动此任务”。网络创建结果未知时不得自动重发创建，提示查历史。双击/pending 排重。

字段前端校验与后台严格校验一致：预算1–100，轮数1–1000，种子0–2147483647，Batch1–256，imgsz32–2048且32倍数，device为cpu或单GPU编号0–63，单试验超时1–86400秒；全部整数。前端不能用空值转0混过去。错误返回安全字段名、稳定理由码和中文修正方法，不能直接返回 Pydantic/底层异常原文、路径或凭据。

## 4 选择、轮询与状态

切换研究立即清空旧 best、参数、验证提示和可用操作；所有 detail/best 请求携带选择代号，只有仍属于当前 study/代号的响应可渲染。单轮询绑定当前ID，切换停止旧timer；避免并行轮询重叠。页面重新加载能恢复上次选择（仅保存ID，不保存参数事实），无效ID显示错误并允许重新选择，不启动训练。

按钮依据服务端 can_stop/can_resume/control_active：运行中提供停止；停止pending显示“正在停止”，不是已停止；暂停/中断提供检查并恢复；BLOCKED 无强制继续。只读请求、模式切换、关闭页面均不停止训练。断网保留最后可信详情，单独标记状态暂不可用；操作错误不能被轮询立即抹掉。409区分训练占用、绑定失效、来源失效等，不一律提示“已有训练”。

历史支持 offset/limit 翻页、当前项高亮及时间/算法/状态/预算/最佳指标摘要；坏记录仍可见。状态中文，原码可在详情保留。搜索运行与用户停止后阶段性最佳明确区分；正式训练只允许已完成、无活动HPO控制器且有成功结果的研究。

## 5 最佳结果与权重

成功结果自动展示排名第一的六参数、指标、最佳epoch、来源trial、实际固定条件。只读加载不自动训练。最佳Trial的 best.pt 提供受控下载入口并标记“搜索阶段模型”，不存在则显示不可用；其他Trial可查看详情。不得以请求传入任意路径下载文件。

新增受控产物路由只接收合法study/trial身份和白名单产物名（本轮仅best.pt、last.pt）；服务端从冻结output_root与权威attempt的run_relpath重建，拒绝路径穿越、链接/重解析点、越根、身份不一致，不可通过伪造record绕过。返回文件名不泄露路径。显示绝对路径不是唯一结果入口。

## 6 使用最佳参数正式训练

主按钮“使用最佳参数正式训练”。六项搜索参数只读；设置正式epochs、batch、imgsz、device，初始显示原研究值并明确需确认，避免把1epoch测试默认为正式生产建议。不提供学习率自由编辑、数据替换、模型替换、命令或输出路径。

建议新增 POST /api/hpo/studies/{study_id}/train-best：

```json
{"trial_id":"hpo_x_t0000","training_config":{"epochs":100,"batch":16,"imgsz":640,"device":"0"}}
```

strict extra=forbid；四个训练字段必填，类型/范围与第3节一致。服务端重验证当前rank-1 SUCCESS、绑定、执行记录与已完成状态；从权威记录重建六参数、原快照、原初始权重、seed及其余固定参数，再只覆盖四项允许条件。warmup等候选条件在正式epochs下重新验证，不合法则安全拒绝，不静默裁剪最佳参数。

复用 ManualRunController、普通训练收尾、原子门禁及受控新train目录，不创建第二种训练执行器。验证/占用失败必须零进程且无新训练目录；初始化写盘失败遵循原fatal策略。202立即返回JSON：run_id、train_name、source及安全状态/结果查询入口；不能通过fetch().json()解析普通训练SSE来等待结束。现有 /api/training/start 的固定验证请求/SSE契约不变。

hpo_source.json持久化source身份、mode=formal、实际四项条件及与搜索条件的差异，关联元数据在启动前写入。关联信息通过普通训练受控持久化事实投影，重载页面/服务后仍能按study找到后续正式训练；不得依赖内存、DOM或仅localStorage。多个正式训练保留全部记录，展示最近一次并可查看历史；不向HPO study/execution写回训练排名。

HPO页显示关联train编号、准备/运行/失败/停止/完成、结果指标、查看监控/结果入口和最终best.pt。终态/指标来自对应run事实，不能把“202已接受”当作完成，不能把Trial指标当正式模型指标。正式权重路由从已验证来源及受控train目录解析，沿用第5节安全规则。元数据不可读时明确提示，不伪造无历史。
