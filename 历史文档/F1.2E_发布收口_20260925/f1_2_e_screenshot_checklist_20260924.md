# F1.2-E 手册截图执行清单

日期：2026-09-24
用途：供艾卡准备《软件安装手册》和《软件操作手册》的实际截图

## 1. 提交方式

- 建议使用 PNG 原图，不要粘贴到聊天软件后再次压缩。
- 文件名使用下表编号，例如 `I-01.png`、`O-01.png`。
- 可以分批提供；每批说明已完成的编号。
- 截图使用脱敏验收环境，不显示 API Key、Token、用户名、邮箱、本机绝对路径、客户名称、真实业务图像或未公开模型内容。
- 截图前关闭无关窗口和通知；只保留与当前步骤有关的区域。
- 分辨率建议不低于 1600×900。内容较长时可以使用同一编号加后缀，如 `O-12a.png`、`O-12b.png`。

## 5. 不需要截图的内容

- API Key、Token 或凭据管理器内容。
- `config.yaml` 原文。
- 完整日志、命令行历史或本机目录树。
- 客户原始数据、客户模型内容或内部网络地址。
- 单元测试输出、Git 状态和开发调试界面。这些属于验收记录，不放入面向用户的操作手册。
