- Docker 只发布一个 `auto-tune` 镜像并运行一个容器；不拆分 Web/Worker，也不发布第二个 Docker 镜像。
- Windows 与 Docker 都运行同一个完整 Studio Web UI 产品；用户不需要调用 API。F1.2 不新增仅 API 的 Engine 模式，也不冻结或公开外部调度 API。
- 提供独立 PT 转 ONNX 手动导出入口，统一接收受控模型或已完成训练产物，不侵入三种训练模式。
- 正式 Docker 启动即使用 NVIDIA 运行时申请 GPU；GPU 不可用时明确报错，不静默回退到 CPU，也不另建 CPU/CUDA 镜像族。
- 数据集、模型、训练结果和配置通过受控目录或 NAS 挂载持久化，镜像内不得固化密钥和业务数据。
- 首版不做 Linux 原生安装、Python Wheel 对外交付、多租户、集群调度、计费和高可用。
- F1.2 功能与部署验证完成后编写软件安装手册；最终验收前由艾卡补齐操作手册和安装手册截图，缺少截图不得判定完整产品验收。
