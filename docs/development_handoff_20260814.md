## 5. 历史开发入口：H1

Q1 已建立“模型可说错、系统不执行错”的最小可信执行边界：

1. 代码生成版本化事实包并绑定运行与证据来源。
2. LLM 只输出符合严格 Schema 的建议。

4. 失败时最多纠错一次；仍失败则记录终态，不启动训练。

## 8. S4 已确认交付边界（不限制后续 Cloud 独立部署）

- Windows 提供 Studio 直接安装包，供单机用户完整使用。
- Docker 只发布一个 `auto-tune` 镜像并运行一个容器；不拆分 Web/Worker，也不发布第二个 Docker 镜像。
- `AUTO_TUNE_MODE=server` 启用完整 Web UI 和统一 API，可在同一网络通过 IP/端口访问。
- `AUTO_TUNE_MODE=engine` 不注册 UI 路由、不加载模板和静态资源，只开放统一 API，供公司平台集成。
- 统一任务入口以 `/api/v1/jobs` 为核心，覆盖数据集分析、直接训练、HPO、LLM 调优、结果分析，以及状态、日志、停止和产物查询。
- 同一镜像在挂载 GPU 时使用 NVIDIA 运行时；未挂载 GPU 时允许 CPU 回退，不另建 CPU/CUDA 镜像族。
- 数据集、模型、训练结果和配置通过受控目录或 NAS 挂载持久化，镜像内不得固化密钥和业务数据。
- 首版不做 Linux 原生安装、Python Wheel 对外交付、多租户、集群调度、计费和高可用。
