## 2. Q1：LLM 可信度 MVP（已完成并合并至 `main`）

**目标**：让“模型可说错、系统不执行错”成为可测试约束。

交付范围：

- 由代码生成版本化事实包，包含来源 ID、值、缺失状态、任务类型和运行绑定。
- 为 LLM 决策建立严格 Schema，限制动作、参数、证据引用和理由字段。
- 确定性校验指标方向、best/final 语义、缺失值、参数类型/范围/依赖、任务适用性和单轮修改数量。
- 校验失败时允许一次结构化纠错；再次失败则记录终态并禁止启动训练。
- 最终改善判断、优胜参数和停止条件继续由代码计算。

首版不做：第二模型复核、知识图谱、多 Agent 辩论、HPO 结果交给 LLM 裁决。

完成记录：Q1.1 事实与证据契约、Q1.2 确定性语义校验、同一事实包的一次纠错、逐次决策审计和审计失败即关闭均已实现。2026-09-02 Codex 独立验收为完整套件 **1484 passed / 2 warnings / 0 skipped**；合法语义决策完成一次最小 Detect CUDA 短训练，三类非法语义决策共六次模型响应均为零命令构造、零训练启动。艾卡已完成线下体验确认，Q1 已通过 GitHub PR #10 合并至 `main`（功能提交 `d6a27f7`，合并提交 `2e930f6`）。语义规则和维护边界见 `llm_tuning_semantic_rules.md`。

## 3. H1：Detect HPO MVP（6–10 人日）

**引擎选择**：产品使用 Optuna TPE，随机搜索作为基线；Ultralytics 遗传调优只做内部基准比较。

首版流程：

1. 用户在直接训练、HPO、LLM 三种策略中选择一种。
2. HPO 创建独立 study，绑定数据快照、模型、目标指标、预算和搜索空间版本。
3. 每个 trial 复用现有训练执行、状态、日志、产物和失败终态。
4. 首版搜索约 6 个高价值参数：`lr0`、`lrf`、`optimizer`、条件化 `momentum`、`weight_decay`、`warmup_epochs`。
5. 按固定 trial 数顺序执行；超时、OOM、用户停止和非法组合形成明确终态。
6. 使用统一指标确定性排名，候选最优参数可再做一次固定配置验证训练。

首版不做：Ray、并行调度、多目标优化、复杂剪枝、自动扩大搜索空间。

验收门槛：TPE 与随机基线均可运行；study 可恢复；失败 trial 不污染优胜结果；同一指标口径可回溯到原始产物；无 LLM 凭据时 HPO 完整可用。

### 5.1 单镜像运行方式

- 只发布一个 `auto-tune` Docker 镜像，并以一个容器承载所选运行模式。
- `AUTO_TUNE_MODE=server`：注册完整 Web UI 与统一 API，允许同一网络通过 IP/端口登录操作。
- `AUTO_TUNE_MODE=engine`：不注册 UI 路由，不加载模板与静态资源，只保留统一 API，供公司大平台调用。
- 数据集分析、直接训练、HPO、LLM 调优和训练结果分析复用同一任务内核，不为 Engine 复制业务实现。
- 挂载 GPU 时使用 NVIDIA 运行时；未挂载 GPU 时允许 CPU 回退，不发布独立 CPU/CUDA 镜像。
- 数据集、模型、结果和配置通过受控目录或 NAS 挂载；容器中不得固化密钥、业务数据、权重或训练结果。

### 5.2 S4 首版明确不做（不限制后续 Cloud 独立部署）

- 第二个 Docker 镜像或 Web/Worker 多容器拆分。
- Linux 原生安装包和 Python Wheel 对外交付。
- 将整套 Studio 安装进公司大平台；平台只通过 Engine 模式 API 集成。
- 多租户、集群调度、计费、高可用和复杂分布式任务编排。

## 9. 估算口径与风险

Studio 剩余 H1+F1+S4 总计 **26–44 人日**；加 Cloud 工程为 **71–119 人日**；另计学习预留后为 **86–144 人日**。Research 暂不估时且不计入上述数字，故不提供完整项目总工期。估算基于一名熟悉现有代码的研发人员，包含设计、实现、自动测试、短训练、界面验证、Windows 与容器交付验证和文档回写；不包含 GPU/外部资源等待、采购或部署审批、重大上游依赖不兼容和新增任务类型。若公司平台接口或目标 GPU 容器环境较晚确定，应取区间上限并预留联调时间。


公司可用和平台对接在 S4 交付，不等待 Research/Cloud。H1/F1 设计期间先确认平台身份、数据目录、任务幂等和产物协议；S4 预算假设公司提供可用测试接口和联调人员，不包含改造公司平台主体。
