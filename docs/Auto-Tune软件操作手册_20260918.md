# Auto-Tune Studio 软件操作手册

版本日期：2026-09-18
适用版本：F1.1 验收冻结版本

## 1. 使用范围

本手册说明 Auto-Tune Studio 已验收功能的页面操作，适用于单人、单机的 YOLOv8 Detect 任务。开始操作前，软件应已由管理员启动并能够正常打开页面。本手册不包含安装、部署、环境配置、升级或卸载；软件安装手册待下一 Part 完成验收后另行编写。

推荐操作顺序：录入项目信息 → 配置大模型服务 → 分析数据集并创建快照 → 选择正常训练、HPO 调优或 LLM 调优 → 在训练监控和历史记录中核对结果。

## 2. 项目信息录入

1. 打开“项目总览”，在“项目”卡片中点击“编辑”。
2. 填写项目名称、项目描述、检测目标和数据类型。内容应说明实际要检测的对象与缺陷类别，避免只填写“测试”等无法区分项目的信息。
3. 按需填写 `data.yaml` 路径和默认模型。正式训练仍应优先使用数据集分析生成的有效快照，以及受控权重库中的模型。
4. 点击“保存”，确认项目卡片显示的新内容正确。
5. 如修改错误，重新点击“编辑”修正；不要直接修改审计文件或历史训练目录。

## 3. 大模型信息录入

### 3.1 文本与调参服务

1. 在“AI 服务配置”中找到“文本与调参服务”，勾选“启用”。
2. 填写供应商、模型名称和 Endpoint。默认使用管理员提供的 DeepSeek 兼容配置；模型名称必须与供应商当前可用名称一致。
3. 只有连接可信的本机或内网兼容服务时，才勾选“允许本地或内网模型端点”。公网 Endpoint 应使用 HTTPS。
4. 在“新 API Key”中输入密钥，点击“保存密钥”。页面不会回显已保存密钥的原文。
5. 点击“保存”保存非敏感配置，再点击“测试连接”。只有连接测试成功后，才开始 LLM 分析或 LLM 调优。

### 3.2 视觉服务

视觉服务的录入步骤与文本服务相同。视觉服务只在需要图像辅助分析时启用；未配置视觉服务不影响数据集分析、正常训练和 HPO 调优。

### 3.3 安全要求

- API Key 不得写入 `config.yaml`、脚本、日志、截图、聊天记录或 Git 仓库。
- 更换密钥时先保存并测试新密钥，再到供应商控制台吊销旧密钥。
- 如果连接失败，依次核对网络、Endpoint、模型名称、账户权限、余额和密钥状态。

## 4. 数据集分析

1. 打开“数据集分析报告”。
2. 点击“浏览”选择 YOLO Detect 数据集目录，或输入完整目录路径。正式入口使用目录，目录中应包含 `images/`、`labels/` 或有效的 `data.yaml`。
3. 点击“分析”，等待页面显示质量评分、图片数、标注数、标注率、模糊比例、目标框尺寸、类别均衡和空间分布等结果。
4. 先处理缺图、缺标签、类别错误、严重模糊和异常框等问题，再用于正式训练。
5. 在“数据集快照”中设置验证集比例和随机种子，点击“创建训练快照”。
6. 只有状态显示“快照有效”时，才进入正常训练、HPO 或可执行的 LLM 调优。快照会复制训练输入，不会移动或改写原始数据；不要手工修改快照内容。

## 5. LLM 调优

1. 先完成至少一次可用训练，并确保其训练目录包含 `results.csv` 和 `args.yaml`。
2. 打开“智能训练”，在训练分析区域选择该训练目录或最近训练，点击“分析”。
3. 在模式中选择“大模型调参”。选择参考运行，设置最大重试次数和评价模式；一般先使用“全面模式”。
4. 查看大模型分析报告和建议参数，再点击“确认并开始训练”。系统会依次进行感知、决策、护栏、执行和探针判断。
5. 所有建议都必须通过事实引用、语义规则、参数护栏和审计写盘后才会执行。校验失败时不会启动训练。
6. 如果日志显示“AI 判断无需调整超参数”“调优结束（keep_params）”和“调优完成”，表示系统正常决定保留参考参数并在训练前结束，不是卡住。
7. 调优完成后核对总体最佳结果。如果原参考训练仍然最好，页面会明确显示“总体最佳：原参考训练”，查看和保存操作也会指向该参考运行。

## 6. HPO 调优

1. 打开“智能训练”，在模式中选择“HPO 算法调参”。HPO 不依赖大模型密钥。
2. 设置试验次数和每次训练轮数，选择已发布的数据集快照和受控权重库中的初始权重。
3. 如需调整采样器、评价模式、计算设备、图片尺寸、Batch、随机种子或单次超时，展开“高级技术选项”。初次使用可保留默认的 TPE 和全面评价。
4. 确认摘要中的数据集、模型、预算、轮数和设备后，点击“创建并开始调优”。提交结果未知时先到“HPO 历史记录”确认，不要连续重复点击。
5. 在进度区域查看试验状态轨道、成功或失败数量、当前最佳结果和最近事件。需要中止时使用“停止”；恢复时选择原研究继续，避免重复创建。
6. 完成后查看排名和最佳参数。只有成功试验参与排名。
7. 如需产出正式模型，在“最佳结果与参数使用”中设置正式训练轮数，点击“使用最佳参数开始正式训练”。正式训练完成后可查看关联结果、打开结果目录或下载 `best.pt`。

## 7. 正常训练

1. 先完成数据集分析并确认训练快照有效。
2. 打开“训练监控”，点击“开始新训练”。
3. 确认 `data.yaml` 指向有效快照，从受控权重库选择初始权重，填写 Epochs、`imgsz` 和 Batch。
4. 点击“开始训练”。系统会执行统一训练门禁；如已有正常训练、LLM 调优或 HPO 训练在运行，需等待其完成或先停止当前任务。
5. 训练过程中查看状态、Epoch、指标和精简日志；排障时展开完整日志。需要中止时点击“停止训练”，不要直接关闭训练进程或删除运行目录。
6. 训练完成后核对 `mAP50`、`mAP50-95`、Precision、Recall、最终状态和报告入口。页面显示 `completed` 后再进行结果分析或下一次训练。

在“智能训练”中选择“按原参数训练”，表示使用参考训练的原参数再训练一次；选择“干运行”只生成计划，不启动真实训练。这两个模式与正常训练入口用途不同。

## 8. 历史记录

1. 打开“历史记录”，查看正常训练和调优产生的运行记录。
2. 可按数据集、来源和状态筛选，按运行名或模型搜索，并按时间、运行名或指标排序。
3. 点击记录查看运行身份、数据快照、模型、实际参数、指标、状态、日志、训练报告和调优审计。
4. 选择 2–5 条记录可进行实验对比。比较前应确认数据快照、初始权重、评价模式和训练条件具有可比性。
5. HPO 研究级历史在“智能训练”的“HPO 历史记录”中查看；普通训练和 LLM 调优结果同时进入统一训练历史。
6. 页面显示“SQLite 索引”时使用本地查询索引；显示“JSON 回退”时仍可读取事实文件，但搜索、排序或分页能力可能受限。必要时先运行索引审计，再按提示重建索引。
7. “导入旧历史”仅用于将遗留运行纳入索引，不会修改原训练产物。导入后应抽查运行名、状态和指标是否一致。

## 9. 常见状态判断

- `completed`：任务已正常结束。
- `failed`：任务失败，先查看错误码和完整日志，不要重复提交相同任务。
- `cancelled`：任务已被用户停止。
- `keep_params`：LLM 决定保留原参数；自动调优可能不启动训练并直接完成。
- “请求结果未知”：先到历史记录或当前任务区确认是否已经创建，避免重复点击。
- “快照损坏”或“快照未解析”：不得开始训练，应重新分析数据集并创建有效快照。

## 10. 操作边界

- 不在训练期间修改数据快照、运行目录或审计文件。
- 不把真实配置、数据集、权重、训练产物、日志或凭据提交到 GitHub。
- 不把单机 Studio 直接暴露为多人服务。
- 不用 HPO 结果再交给 LLM 裁决；正常训练、HPO 和 LLM 调优是三种独立策略。
- 软件安装、部署、升级、卸载和 Docker 操作不属于本手册，待下一 Part 验收后由安装手册统一说明。
