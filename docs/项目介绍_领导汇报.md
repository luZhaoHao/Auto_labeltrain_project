# 口服液瓶盖瑕疵检测 — YOLOv8 自动调优系统

## 项目汇报

---

## 一、项目背景与解决的问题

### 面临的问题

在工业视觉检测、质检自动化等场景中，企业和工程师普遍面临以下痛点：

| 问题 | 影响 |
|------|------|
| **AI 训练门槛高** | 使用 YOLO 等深度学习模型需要专业知识，业务人员难以独立完成模型训练和调优 |
| **手动调参耗时费力** | 学习率、批次大小、数据增强等超参数需要反复试错，一次完整调优可能耗费数天 |
| **数据质量难以把控** | 训练前无法预知数据集是否存在模糊、过曝、标注错误等问题，常常训练完才发现效果差 |
| **训练结果缺乏深度分析** | 仅靠 mAP、精确率等指标难以定位问题根源，不知道模型为什么表现不好 |
| **缺乏自动化闭环流程** | 从数据集检查→训练→分析→调优，各环节割裂，依赖人工衔接 |
| **经验难以沉淀和复用** | 调参经验存储在个人头脑中，人员变动导致经验流失，无法系统化传承 |

### 系统解决思路

采用 **AI 视觉检测** 替代人工目检，用 YOLOv8 目标检测模型自动识别瓶盖瑕疵。同时，针对 YOLO 模型训练门槛高、参数调优繁琐的问题，开发了 **自动化调优引擎**，降低 AI 落地的人工干预成本。

## 二、技术方案

### 整体架构

系统采用 **三模块闭环架构**：

```
数据集 → [Module A 数据集分析] → [Module B 训练分析] → [Module C 自动调优] → 最优模型
                                                                  ↑
                                                                  闭环反馈
```

### Module A — 数据集质量分析

自动检测数据集存在的问题，在训练前就把关数据质量：

- **图像质量检测**：模糊度、曝光异常（过曝/欠曝）、信噪比
- **标注质量检测**：标注覆盖率、标注框大小分布
- **类别分布分析**：各类别样本数量是否均衡、是否存在长尾分布
- **空间位置偏差**：目标是否集中在图像中心区域
- **特征聚类分析**：通过 DBSCAN 聚类发现异常图像

**效果**：在训练前就发现数据问题，避免"垃圾进垃圾出"。

### Module B — 训练结果深度分析

训练完成后，自动从三个层面分析模型表现：

| 层级 | 方法 | 成本 |
|------|------|------|
| **Stage 1** Python 规则分析 | 曲线趋势分析、过拟合检测、早停检测、多轮次对比 | 零成本 |
| **Stage 2** LLM 文本诊断 | DeepSeek 大模型阅读指标数据，用自然语言描述模型表现和改进建议 | 约 200 tokens/次 |
| **Stage 3** 视觉分析 | Qwen-VL 多模态模型分析混淆矩阵图、错误裁剪图，从视觉角度发现问题 | 约 500 tokens/次 |

**效果**：不仅告诉你"指标是多少"，还能告诉你"问题可能出在哪、建议怎么做"。

### Module C — 自动调优闭环

核心创新点：**AI 自动调整超参数**，替代人工试错。

流程：
1. **感知层** — 读取 Module A + Module B 的分析结果
2. **决策层** — DeepSeek LLM 根据当前模型表现，分析应该调整哪些参数（学习率、批次大小、数据增强等）
3. **安全护栏** — 校验参数范围，防止 LLM 给出不合理参数（如批次大小超出显存）
4. **执行层** — 自动修改参数并启动 YOLO 训练
5. **探针监控** — 前 10 个 epoch 快速评估训练趋势，决定继续/重试/终止
6. **闭环反馈** — 训练完成后自动分析效果，进入下一轮调优

**效果**：从"人工反复试参"变为"AI 自动迭代"。

### Web 交互界面

基于 FastAPI + SSE 的实时流式 Web 界面，操作工无需写代码即可完成：
- 数据集上传与分析
- 训练启动与实时监控
- 结果查看与报告导出
- 自动调优一键启动

### 已完成的功能

| 功能 | 状态 |

| LLM 文本诊断报告 | ✅ 已上线 |

| 端到端训练流程（上传→分析→训练→看结果） | ✅ 已验证通过 |
| 自动调优闭环（AI 自主迭代参数） | ✅ 已上线 |
| 最佳迭代追踪与报告保存 | ✅ 已上线 |

### 达到的效果

- **降低 AI 使用门槛**：操作工只需上传数据、点击按钮，即可完成模型训练
- **减少人工调参工作量**：AI 自动完成超参数搜索，节省数天的试错时间
- **数据质量问题前置**：训练前即可发现数据集问题，避免无效训练
- **分析报告可视化**：指标、问题、建议一目了然，非技术人员也能理解
- **全流程可追溯**：每次训练都有完整的分析报告和日志存档

### 技术指标

- 模型框架：YOLOv8（Ultralytics）
- LLM 诊断：DeepSeek Flash 模型
- 视觉分析：Qwen-VL Flash 多模态模型
- 参数安全机制：护栏规则确保参数不越界
- 训练监控：前 10 epoch 探针，支持继续/重试/终止决策
